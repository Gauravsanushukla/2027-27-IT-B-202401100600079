# Setup Guide

## Prerequisites
- Docker & Docker Compose
- Node.js 20+
- Terraform (for cloud deployment)
- kubectl (for Kubernetes deployment)

## Local Setup
1. `cp .env.example .env`
2. `docker compose up --build`
3. Visit `http://localhost:3000`
